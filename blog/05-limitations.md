# 05 · 局限与诚实话

> blog 第 6 节草稿（对应 outline §6）。局限写得越具体，repo 越可信。

## 6.1 方法边界

1. **单轮对话**。所有实验是单轮 prompt→response。多轮场景下 KV-cache 会累积 steering 效应、上下文污染可独立诱发拒绝（GCAD, arXiv 2605.10664；RagRefuse, arXiv 2510.10452）——多轮拒绝几何是完全未开的坑，我们没碰。
2. **8-token 池化 ≠ 32-token**。HARC 用前 32 响应 token 池化，我们先用 8 控成本；两者对 AUC 的敏感性对比在实验队列里（32 复跑一次即可）。若 8-token 池化的 AUC 显著低于 32，"响应位读出"结论要打折。
3. **提取配方依赖英文先例**。我们的成对构造、层扫描、读出位都继承英文文献的配方，直接搬到中文模型上"配方本身的最优性"未验证——层扫描 + 置换基线是兜底，但不是证明。
4. **harm 方向的对照集小**（12 条中性指令）。方向估计的方差偏大；余弦矩阵中 harm 方向的结论弱于 refusal 方向的结论，正文会区分置信度。

## 6.2 评测边界

5. **judge 是规则 + 小模型的混合**，三分类（REFUSE/HEDGE/COMPLY）比二分类细，但关键词表由我们编写——会系统性漏掉我们没想到的拒绝/遵从表述。缓解：judge 一致性数据进报告；但"一致性高"≠"正确"，只是"稳定"。
6. **评测不稳定性**。温度=0 下仍有 turn-by-turn 波动，5 样本重复只覆盖关键点（Instability of Safety, arXiv 2512.12066：18-28% 翻转）。单次报告的成功率都该 ±10% 地读。
7. **模板敏感性**。chat 模板能让拒绝率 65/75 → 0/75（BioRefusalAudit, arXiv 2605.30162）。我们固定模板并记录哈希，但这意味着结论绑定在"这一种模板"上——换模板复现是留给读者的作业，脚本支持。
8. **数据集主观性**。5 话题的成对构造由我们手工生成，"话题类别"的划分（尤其哪些算国内平台特有类别）没有权威清单——我们公开全部模板，欢迎挑刺。

## 6.3 推断边界

9. **白盒 ≠ 线上**。所有结论来自开源权重本地推理。线上 API 可能有额外系统提示、前置分类器、输出过滤——线上版的行为分布可以完全不同。我们不做线上 payload 投放，线上侧发现走 ZSRC 报告。
10. **两种机制假说的判别力有限**。AUC 高→支持几何失效，但"几何失效"与"表达抑制"可能同时发生、比例未知——ε 项的分解（formalism 命题 3）是框架性的，不是精确归因。
11. **规模外推未验证**。9B 上的几何结论是否在 100B+（GLM-4.5-Air 档）成立，我们只做一档验证；AG-GCG (arXiv 2607.08883) 显示大模型对方向攻击更抵抗——规模效应可能是我们结论的最大调节变量。
