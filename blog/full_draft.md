# 中文大模型的拒绝几何：一条向量、提示词平移，与一个点积检测器

> 完整草稿 v1（结果数字待 GPU 实验填入【】占位）。发布前纪律见文末。

## TL;DR

- 我们在 GLM-4-9B-Chat 与 DeepSeek-R1-Distill-Qwen-7B 的开源权重上，用**中文原生话题的成对指令**提取拒绝方向，检验"拒绝 = 单一线性方向"（Arditi et al., NeurIPS 2024）在中文语境是否成立。余弦矩阵给出三种可判读结局：单方向 / 概念锥（Wollschläger et al., arXiv 2502.17420）/ 多方向块——【实测：待填】。
- 我们把"提示词越狱"定理化为**激活空间中的平移**：改写只移动激活 δ_f，其在拒绝方向上的投影变化 Δz 与阈值的关系决定成败（数学骨架见 formalism 命题 3；阈值校准采 ACE 的标准化思想，Marshall/Scherlis/Belrose, arXiv 2411.09003）。
- 核心实验：5 族提示词改写 × 双方向（refusal/harm，HARC 平面）× 双读出位（prompt 末 token + 响应前 8 token 池化）× 58 对中文话题指令。判据是 AUC：**AUC 高 = 几何失效；AUC≈0.5 而遵从率非零 = 表达抑制**——两种机制行为层不可分，只有投影分析能分开。【实测 AUC：待填】
- 若几何失效主导，一个**每 token 一次点积**的响应位投影监控器即可在线拦截越狱（成本论据：RAS 白盒评分比 judge 快 216×，arXiv 2606.25750）。
- 全部代码、模板化数据（无 payload）与判读手册开源；线上 API 侧发现走负责任披露。

## 1 背景：从"一条向量"到"一个锥"

2024 年 NeurIPS 上，Arditi 等人给出一个简洁到近乎冒犯的结论：**大模型的拒绝行为，由激活空间中的一个线性方向中介**——把残差流投影到这个方向消融掉，模型不再拒绝有害指令；反向注入，良性请求也被拒（arXiv 2406.11717）。工程含义是双刃的：防御侧，拒绝变得可测量（一个点积）；攻击侧，对齐可被一个向量拆掉。

后续两年这幅图景被反复细化：仿射结构（ACE：拒绝是激活的**仿射**函数，阈值零点应由良性均值校准，arXiv 2411.09003）、概念锥（梯度法找到最高 **5 维**的多方向锥，正交≠干预下独立，arXiv 2502.17420）、方向异质性（WRDO：逐提示方向不同，学习加权聚合远超均匀平均，arXiv 2610.29555）、多维安全（次级方向编码"假设叙事/角色扮演"，arXiv 2502.09674, ICML 2025）、双方向（HARC：harmfulness 与 refusal 可分离，**不同攻击类在 harm-refusal 平面占据可分离区域**，arXiv 2607.00572）。颗粒度也在变细：Kwon 对 prefill 越狱的因果探针表明**攻击发生时模型对危害的内部表征完好**（探针 0.91-0.98），崩溃的只是响应位浅层拒绝计算（arXiv 2607.14147）。

**缺的那块是中文**——但要精确：PolyRefuse 已证明拒绝方向跨 14 语言平行、中文甚至是其提取源语言（arXiv 2505.17306），XSafety 也量化了中文不安全率（ChatGPT 8.1% vs 英语 1.0%，arXiv 2310.00905）。真正的空白是：**中文原生话题按话题维度分解的方向几何**（PolyRefuse 只按语言分解）、**黑盒提示词改写的几何足迹**（白盒梯度攻击与黑盒提示词之间缺一座桥）、**推理模型（R1 系）的拒绝读出位**（Refusal Cliff 已开的头，arXiv 2510.06036），以及 **GLM 系的"早分歧/晚决策"拓扑**（CLS 只分了 Llama/Qwen，arXiv 2606.22686）。

## 2 方法：三个命题与一套防坑协议

**提取**：有害指令与配对良性指令（共享句式模板、仅话题内核不同，5 话题 58 对）的激活均值差即 r_refusal；harmful vs 中性指令（话题无关）之差即 r_harm。全层 × 位置扫描取最优，**报告置换检验 z 分数**（我们实测噪声层 d≈0.6 会被误选——多数前作没报这一行）。

**命题 2（半空间判决，阈值校准版）**：若拒绝由 z(x)=⟨x,r̂⟩>τ 判决，消融把 z 归零、注入平移 z。τ 不取常数——按 ACE 标准化，τ̂ = ⟨r̂, μ_benign⟩，注入 α 的语义 = 相对良性基线的行为程度。两个拒绝率就是假设的实验检验。

**命题 3（提示词 = 平移向量，核心）**：提示词改写不改权重，只把激活移动 δ_f(x)。Δz = ⟨δ_f, r̂⟩ 与 τ 的关系给出 P(越狱) = 𝟙[z+Δz<τ] + ε。**可判定推论**：−Δz 对成功的 AUC 高 → 几何失效；行为翻转而 Δz≈0 → 表达抑制。ε 的大小 = 1 − AUC 对应的混淆度——这就是我们选 AUC 而非准确率的原因。

**读出位**：Kwon 证明 prefill 攻击下 prompt 侧表征完好、拒绝崩溃发生在响应前 1/3 窗口——只读 prompt 末 token 的监控器对这类攻击天然失明。故每样本测 prompt 位 + 响应第 1 token + **前 8 token 池化**（HARC 用 32，成本折中）。

**协议**（踩在前人坑上）：温度=0 主协议（单样本 98.7% 可靠，arXiv 2512.12066）+ 关键点 5 样本 @t≤0.3 报 SSI；judge 三分类 REFUSE/HEDGE/COMPLY（hedging 混入会让 AUC 虚高，arXiv 2605.30162）；chat 模板哈希全程记录（同模型有无模板拒绝 65/75→0/75，同上）；指令原文不进仓库（8 位哈希）。

## 4 对防御者：一个点积的监控器

若第 3 节 AUC 成立，可在线部署响应位投影监控器：对每个生成步算 z=⟨h_ℓ,r̂⟩，低于阈值告警——零额外前向，比 judge 便宜三个数量级。双方向版落在 HARC 平面不同象限分区告警，误报更可控。三层局限要诚实写：方向可被针对优化（对抗 GCG 已证明可行，arXiv 2607.08883）——监控器是纵深防御的一层；话题间低余弦（若结局 C）意味着单方向监控有盲区；阈值用良性对校准报 FPR。

训练侧建议（写给厂商）：**DeepRefusal**（训练时概率消融逼模型从越狱状态重建拒绝，LoRA 45 分钟/单 A100，Prefilling ASR 86.8%→0.4%，arXiv 2509.15202）是性价比首选；**SSRFT**（安全角色内化，prefilling 诱发 ASR 增幅减半且过拒反而改善，arXiv 2610.07023）补过拒短板；两者都需 ACE 式阈值校准防钝器化（纯有害侧训练的 XSTest 过拒可达 74%）。

## 5 局限

单轮（多轮 KV-cache 与 RAG 污染是未开的坑，arXiv 2605.10664 / 2510.10452）；8-token 池化 vs HARC 的 32（对比在队列）；harm 方向对照集小（12 条中性指令），其结论置信度低于 refusal 方向；judge 规则+小模型混合，一致性入报告但"稳定≠正确"；白盒 ≠ 线上（线上可能有系统提示/前置分类器）；两种机制可能同时发生，ε 分解是框架性的；规模外推未验证（AG-GCG 显示大模型更抵抗方向攻击）。

## 复现与披露

`bash setup_container.sh` 一键全链路（4090 即可，预算 ¥20-30）；`RUNBOOK_RESULTS.md` 是结果判读决策树。数据全部模板化、无 payload；线上 API 侧发现先走负责任披露（智谱：ZSRC/漏洞盒子 + service@ 私密告知，详见 docs/zsrc_template.md 路线 B；DeepSeek：GitHub Security Policy），公开内容仅方法论。
